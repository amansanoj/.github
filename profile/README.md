I develop macOS apps, web applications, and ESP32 firmware. Most of my work involves getting separate systems to communicate: a physical controller with a Mac, a Bluetooth light with Apple Home, or video players across a watch party.

### Selected Projects

#### [Macro Pad](https://github.com/amansanoj/macro-pad)
<sub>Swift · SwiftUI · CoreBluetooth · C++</sub>

A four-key Bluetooth controller with a native macOS app. Assign actions per application without reflashing the device. The firmware and companion share a versioned protocol with input deduplication and reconnection handling.

#### [Tether](https://github.com/amansanoj/tether)
<sub>TypeScript · Bun · WebSockets</sub>

A watch-party server that keeps multiple players on the same timeline. An authoritative playback clock drives drift correction, linked rooms, and reconnect recovery. The host can inspect participant latency and buffering state.

#### [NeonOS](https://github.com/amansanoj/neon-os)
<sub>C++ · ESP32 · HomeSpan</sub>

An Apple Home bridge for a BLE RGB light, with an OLED interface and physical controls. The update client verifies signed firmware and supports boot-health rollback. Native fault tests cover the updater; real-device OTA acceptance is still pending.

#### [Cardputer Now Playing](https://github.com/amansanoj/cardputer-nowplaying)
<sub>C++ · Python · ESP32-S3</sub>

An Apple Music display and controller for the M5Stack Cardputer. A macOS companion sends track information and artwork over BLE; the device caches artwork locally and sends playback commands back from its keyboard.
